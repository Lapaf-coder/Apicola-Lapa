# Apícola Lapa

Sistema Web de Gestión Apícola desarrollado con Django.

## Sprint 0

### Sprint Goal

Configurar el entorno de desarrollo del proyecto, crear la estructura inicial en Django, configurar Git y GitHub, establecer el tablero Kanban, crear las aplicaciones principales y dejar listo el proyecto para iniciar el desarrollo del Sprint 1.

## Tecnologías

- Python 3
- Django 5
- SQLite3
- Git
- GitHub
